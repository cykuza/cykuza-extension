Run your own Electrum server

Cykuza can ship shared Electrum defaults for convenience. Those hosts see addresses you query and can lie about balances, history, fees, or broadcast. A personal server you control is the stronger trust model.

What you get

Your wallet talks to Electrum over wss:// (TLS). Dual-server verify (when two endpoints are configured) cross-checks balance/UTXO fingerprints and broadcast txids — it does not replace trusting who runs the servers.

1. Run ElectrumX for Cyberyen

  1. Run a Cyberyen full node and an ElectrumX (or compatible) server pointed at that node.
  2. Expose Electrum over TLS as wss://your-host:port. Plain ws:// is rejected by the wallet.
  3. Prefer two independent hosts if you want dual-server verify to mean something beyond a single operator.

2. Add it in Cykuza

  1. Open the extension → Settings → Network.
  2. Add your wss:// URL. Chrome will ask for host permission — grant only hosts you intend to use.
  3. Optionally remove built-in servers so traffic no longer hits shared defaults.
  4. Keep Verify with second server on when two or more endpoints are configured.

3. Source / contributor builds

Builds without injected defaults have an empty mainnet list — you must add a custom wss:// before Refresh or Send. Release builds may include shared defaults via CYKUZA_ELECTRUM_MAINNET_URLS; treat them as optional convenience, not a privacy guarantee.

Keys never leave your device. Electrum only learns what you query on-chain.
